# 03 星球与演化（单星肉鸽版 · v3）

> **v3（2026-10-22）**：星球是**地图**，不再是战场。玩家在星球上选落点、看浊泉和星相演化；选定落点后进入一个独立的 HD-2D 立体沙盘打仗（[04](04_战斗.md) 第 2 节）。原因：在球面上布阵，弧度、六边格和浊的网点混在一起，小单位看不清（HTML 原型验证过）。

> 目前只做一颗星：**苔眠星**。每一局用新的种子重新生成地形和浊泉。
> 旧版的多星球尺寸、星球专属地形、生态布置细节已归档到 [future/](future/)，生态和栖地放到第二阶段（见第 9 节）。

## 1. 六边格星球

### 1.1 网格
- 把二十面体每条边分成 n 段，投影到球面，再取对偶，得到六边格球（Goldberg 多面体）。
- 格数 = **10n² + 2**，其中永远有 12 个五边格，其余是六边格。五边格的规则和六边格完全相同，只是少一个邻居。
- 苔眠星 **n = 6，362 格**。相邻格中心的夹角约 0.20 弧度（≈ 1.2 / n），从一极走到另一极约 16 格。
- 星球地图距离只用于落点与浊泉关系；战斗距离改用独立方格坐标，不得把球面夹角用于战斗射程。

### 1.2 每一格记录的数据

| 字段 | 类型 | 说明 |
|---|---|---|
| `dir` | 单位向量 | 格中心方向 |
| `neighbors` | 5 或 6 个格编号 | 相邻格 |
| `terrain` | 枚举 | 见第 2 节 |
| `height` | 0–1 | 噪声生成的高度排名 |
| `murk` | 0–1 | 浊的浓度 |
| `clear` | 0–1 | 清亮程度（动画用；逻辑上 ≥ 1 就算清亮） |
| `mark` | 载具编号 | 地面印记（哪种载具在这里落过地） |
| `flags` | 位掩码 | 浊泉、清泉、落点区域、高亮状态等 |

## 2. 地形

按噪声把高度分档，再用第二层噪声区分草和林。星球上的地形**不直接参与战斗**，它决定落点进去以后战场的地貌（见第 4.3 节）；具体的战斗效果在战场的格子上生效（见 [04](04_战斗.md) 第 2.2 节）。

| 地形 | 生成规则 | 进去以后的战场 |
|---|---|---|
| 深水 | 四周全是水的水格 | 不能当落点中心 |
| 浅水 | 高度最低的 20% | 水多的区域 → 湖畔 |
| 沙滩 | 挨着水的低地 | 沙多的区域 → 沙岸 |
| 草地 | 默认 | → 草原 |
| 林地 | 第二层噪声高的草地 | 林多的区域 → 林间 |
| 山石 | 高度前 2.8%–11.5% | 山多的区域 → 山脚（高台多） |
| 雪顶 | 高度前 2.8% | 雪多的区域 → 雪坡 |

每局随机的地形，让「这一局在哪里打」本身就不一样：有的局湖多，适合水属性；有的局山多，适合远程。

## 3. 浊与浊泉

### 3.1 浊
- 每一格有底浊值（噪声决定），越浓越灰。
- 清亮时，颜色按像素随机地从灰变回本色。
- 浊很浓的地方（`murk` > 0.7）会飘灰絮粒子，提示这里危险。

### 3.2 浊泉
- **每局 3 口**：都在陆地上、不挨水，彼此夹角至少 75°。离降临点最远的一口是**星心之泉**。
- 画面：缓慢旋转的紫色漩涡，近景带紫光。星心之泉更大，周围有一圈慢慢转的浊苔。
- **浊泉等级**：第 1 天是 1 级，每过一天 +1（浊潮，见 [07](07_一局的结构与局外成长.md) 第 3 节）。战斗时用离落点最近的那口浊泉的等级。
- **松动**：离浊泉 6 格以内有 2 个打赢过的落点。
- **可以挑战**：松动 + 星相够了（第一口要初醒，第二口要萌青，星心之泉要繁茂并且另外两口都封住）。满足时，泉主作为额外的落点出现。
- **封泉**：泉主战胜利，浊泉变成青色的清泉，周围 3 圈清亮。清泉格永久是露眼格。

### 3.3 浊的退去和回浊
- **退去**（萌青以后，每次回星时结算）：还浊着的陆地格，如果有 3 个以上清亮的邻居、而且离活着的浊泉超过 2 格，`murk −0.34`。降到 0 就变清亮。
- **回浊**（每天的浊潮）：每口活着的浊泉让离它 4 格以内的 2 个清亮格重新变浊（`murk = 0.6`）。第 5 天起翻倍。
- 回浊会降低清亮度，但星相只升不降。

## 4. 落点

### 4.1 落点是什么
- 每个时辰，星球上标出 **3 个候选落点**（能挑战泉主时多一个），玩家选一个。规则见 [07](07_一局的结构与局外成长.md) 第 5 节。
- 这相当于肉鸽游戏的「地图节点」，地图就是这颗星球：转动星球，看三个落点分别在哪里、离哪口浊泉近、在什么地形上。
- 每个落点在星球上对应一块**落点区域**：中心一格加外面两圈，共 19 个六边格。这块区域决定了进去以后的战场是什么样子（第 4.3 节），也是打赢后星球上变清亮的地方（第 5 节）。

### 4.2 合格的落点中心

| 规则 | 说明 |
|---|---|
| 中心不是水，也没有清亮 | — |
| 离最近的活着的浊泉超过 3 格 | 泉主落点除外 |
| 区域 19 格里的陆地至少 12 格 | — |
| 预计新清亮格至少 8 格 | 保证每块地都值得打 |

### 4.3 从星球到战场
落点区域的地形比例决定战场的**地貌家族**，再从这个家族的模板里挑一个（规则和模板见 [data/战场模板](data/战场模板.md)）：

| 区域里 | 战场 |
|---|---|
| 浊泉的首领落点 | 泉口 / 星心之泉 |
| 雪顶 ≥ 15% | 雪坡 |
| 水 ≥ 25% | 湖畔 |
| 山石 ≥ 25% | 山脚 |
| 林地 ≥ 35% | 林间 |
| 沙滩 ≥ 25% | 沙岸 |
| 其他 | 草原 |

- 距离浊泉影响难度，不再挑选长路/短路模板。模板只描述地形、中心心、边界入口和装饰，不存敌人的固定路线。
- 多向特征增加入口压力；敌人根据当前阵型动态寻路。
- 战场的配色和星球上那块地一致（同样的草色、水色），时辰和天气也一致。

### 4.4 落点面板显示的信息
类型、地貌家族（用文字说明地形与入口数量）、最近浊泉的距离和方向、浊泉等级、浊气浓淡、预计来浊数量、落点特征、能看到的浊化小妖、预计新清亮格数、奖励预览、当前时辰。

### 4.5 落点特征
落点生成时按条件挂 0–2 个特征：

| 特征 | 出现条件 | 效果 |
|---|---|---|
| 露眼 | 区域里有浅水，或挨着清泉 | 战场多 1 个露眼格 |
| 多向 | 两口活着的浊泉到落点的距离差不超过 2 格 | 增加同时活跃的入口，分配本波总量；不预铺路线 |
| 夜战 | 时辰是夜 | 见 [04](04_战斗.md) 第 7.3 节 |
| 雾中 | 当天天气是雾 | 所有射程 −0.5，光属性不受影响 |
| 浊涌 | 离浊泉 ≤ 4 格 | 第三波数量 ×2，奖励品质 +1 档 |
| 迷途 | 第 2 天起随机 | 一只浊化小妖混进第 2 波（多一个结缘机会） |

## 5. 净化

战斗胜利后，先在**战场**上：清亮从心开始一格格扩散到整个沙盘（灰色褪去、草冒出来、露珠往上飘，约 3 秒）。然后回到**星球**：

- **守心战胜利**：落点中心周围 3 圈清亮。
- **结缘战胜利**：中心周围 1 圈。
- **泉主战胜利**：浊泉周围 3 圈，浊泉变清泉。
- 星球上清亮的格子保留载具的地面印记。
- 星球上的动画：由内往外一圈圈由灰变回本色，约 2 秒。

## 6. 星相：一局里的星球演化

**清亮度** = 清亮的陆地格 ÷ 全部陆地格。星相由清亮度和封泉推进（数值见 [07](07_一局的结构与局外成长.md) 第 4 节）：

| 星相 | 条件 | 星球的变化 | 对玩家 |
|---|---|---|---|
| **灰寂** | 开局 | 一片灰，没有风，云不动，水是浑的灰绿色 | — |
| **初醒** | 清亮度 10% | 起风，云开始流动；下第一场小雨；全星的水变清 | 心灯 +3，出阵 +1，第一口浊泉可以挑战 |
| **萌青** | 清亮度 25% | 浊开始退去；清亮的草地冒出草簇 | 心灯 +3，出阵 +1，第二口浊泉可以挑战 |
| **繁茂** | 清亮度 45% | 清亮的地方长出小树；大气光晕变亮；开始有天气 | 心灯 +3，出阵 +1，星心之泉可以挑战（另两口已封时） |
| **清欢** | 星心被洗净 | 星心醒来；剩下的浊一起散掉；整颗星亮起来 | 胜利 |

- 升档时有 6 秒演出：镜头拉远，一圈亮环从刚清亮的落点扩散到全星；音乐加一个声部（见 [10 音频](10_音频.md)）。
- 顶栏一直显示「下一星相：清亮 x% / y%」以及三口浊泉的状态。
- 一局大约第 1、2、5、8 场战斗前后各升一次档，保证每局都能看到星球变化。

## 7. 时辰与天气

- 一天 4 个时辰：晨、午、暮、夜。每选一个落点过一个时辰。
- 光照：晨偏暖粉、午明亮、暮橙紫、夜深蓝（夜景保留冷色环境与暖光源对比，不依赖旧素材）。
- 夜里的守心战有夜战规则（见 [04](04_战斗.md) 第 7.3 节）。
- **天气**（繁茂以后，每天抽一次）：

| 天气 | 战斗效果 |
|---|---|
| 晴 | 光属性力 +10% |
| 雨 | 水属性力 +10%，暖属性力 −10%，产露 +20% |
| 雾 | 落点带「雾中」特征 |
| 风 | 汽属性力 +10%，飞行的浊速度 +15% |

## 8. 镜头（星球视图）

| 状态 | 设置 |
|---|---|
| 星球视图 | 星球偏左，右边留给落点面板；星球半径约占画面高度的 40% |
| 选中落点 | 星球平滑转到落点正对镜头（0.6 秒），落点区域描边 |
| 进入战场 | 镜头拉近落点区域（1.2 秒）→ 像素溶解 → 切换到战场场景 |
| 回到星球 | 战场溶解 → 星球视图从落点区域拉远（1.2 秒）→ 播放星球上的净化动画 |
| 转动 | 使用无极区死角的轨迹球/四元数全向旋转；拖动可连续转过 360°，能看背面和两极；带惯性，空闲缓慢自转可关闭；「回到落点」0.8 秒转回 |
| 星相演出 | 拉远一点，绕星转半圈 |

拾取必须考虑深度遮挡，只允许选择当前可见球面的标记；点击与拖动区分。右侧落点列表可以定位背面节点，但必须先转到正面再确认进入。转动、缩放、选中、回星后保留同一颗星的进度，不重新随机生成。

战场的镜头见 [04](04_战斗.md) 第 2.5 节。

## 9. 第二阶段：生态与栖地

首发的单星肉鸽**先不做**生态布置和栖地。原因：肉鸽每局都重来，花大量时间摆生态物在一局里不划算；而且这一块和 Pokopia 撞得最厉害（见 [15 竞品调研](15_竞品调研.md)）。

以后可能的做法（备忘）：
- 生态物作为**星签式的奖励**出现，拿到后放在清亮的格子上，给附近的落点加成（例如「小泉：周围 2 格的落点进去后多一个露眼格」）。
- 凑成栖地后，下一个时辰该处必出一个「迷途小妖」奇遇。

完整的生态物和栖地设计保留在 [data/生态物与栖地](data/生态物与栖地.md)，供以后使用。
