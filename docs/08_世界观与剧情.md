# 08 世界观与剧情（单星肉鸽版）

> 目前只做苔眠星一颗星，故事分散在一局一局里讲（像《哈迪斯》）。旧版 6 颗星的完整主线已归档到 [future/](future/)。

## 1. 世界

### 1.1 星海与小星
- 夜空里漂着许多小星。每颗小星都有一位**星心**：星球自己的灵，可能是一只老龟、一头云鲸、一座会走的灶。
- 星心醒着的时候，星球上有风、有雨、有小妖。星心睡着了，星球就慢慢落满灰。

### 1.2 浊
- 浊不是坏东西，它是**累积下来的疲倦**。星心太累了，睡得太沉，做的梦就变成灰，一层层落在星球上。
- 浊会聚成一团团会动的东西（浊团、灰絮……），它们没有心，只是本能地往亮的地方走（所以会去碰「心」）。打散它们，它们就变回露水。
- 浊落在小妖身上，小妖就会迷糊、发脾气，这就是「浊化」。洗净以后，它们只会觉得睡了一个很长的午觉。

### 1.3 清星人
- 主角是一位**清星人**：在星海里旅行、替睡着的小星扫灰的人。
- 清星人不是战士。他们带着小妖，用灯、伞、雨云这些小东西落到星球上，在落脚的地方「点一个心」，让小妖守着它，等浊散开。
- 主角没有固定的性别和外形设定，开局可以选外观（3 种发型 × 4 种衣服配色），默认名字「阿青」，可以改。全文不用第三人称代词称呼主角。

### 1.4 小院和灯婆婆
- 小院是清星人的家，在一块漂在星海里的小浮屿上，远远看得见苔眠星。
- 院里的**心灯**里住着灯婆婆：一团说话慢悠悠的老火苗。她是导师，也是整个故事的讲述者。她知道很多星星的事，但不知道浊从哪里来。

### 1.5 灰灰
- 第一局开始前，主角在小院里发现一小团没散掉的浊。它不攻击，也不怕光，只是好奇地跟着主角。主角给它起名叫「灰灰」。
- 灰灰不能战斗，也不能结缘。它一直跟在主角身边，每胜利一局，它的颜色就淡一点。
- 灰灰是故事的暗线：它其实是最老的那盏灯「长明」掉下来的一小片疲倦。

## 2. 角色

| 角色 | 是谁 | 性格 | 在游戏里做什么 |
|---|---|---|---|
| 阿青（主角） | 清星人 | 不说话的主角，只在选项里表达 | 玩家 |
| 灯婆婆 | 心灯里的老火苗 | 慢、爱唠叨、偶尔说漏嘴自己年轻时的事 | 每局开始和结束时说话；故事的讲述者 |
| 灰灰 | 一小团没散掉的浊 | 好奇、黏人、不会说话，只会「噗」 | 一直跟着主角；暗线 |
| 慢慢 | 背着铺子的大蜗牛 | 慢、精打细算、喜欢讲价 | 行商落点 |
| 眠眠 | 苔眠星的星心，一只老苔龟 | 睡了太久，醒来第一句话总是「几点了」 | 每局的最终首领；胜利后的故事主角 |

## 3. 故事：一局讲一点

### 3.1 设定
- 苔眠星的星心眠眠睡得太沉，梦变成了浊，一层层落在星球上。
- 每一次清星人落到苔眠星，看到的都是「眠眠的一个梦」：地形不一样，浊泉的位置不一样，但星球是同一颗。这就是每局地形都不同的理由。
- 灯婆婆说：「它做了很多很多梦。每扫干净一个，它就能睡得安稳一点。」

### 3.2 故事怎么推进

| 时机 | 内容 |
|---|---|
| 每局开始 | 灯婆婆一两句话，内容和上一局的结果有关（例如上局在第二口浊泉前倒下：「那口泉有点凶吧？慢慢来。」） |
| 每局结束 | 胜：眠眠醒来一小会儿，说一句话；败：「灯熄了」，灯婆婆安慰一句 |
| 奇遇「灯婆婆的信」 | 故事碎片，一共 12 封，讲灯婆婆和长明（星海最老的灯）的往事 |
| 第一次封泉 | 浊泉里浮出一段眠眠的梦（一句话加一幅像素小画） |
| 每次胜利 | 解锁眠眠的一段记忆：它为什么这么累 |
| 灰灰 | 每胜利一次，灰灰的颜色淡一点 |

### 3.3 结局

| 结局 | 条件 | 内容 |
|---|---|---|
| 普通结局 | 第一次胜利 | 眠眠醒来：「几点了？」灯婆婆：「早着呢，慢慢来。」 |
| 梦的尽头 | 胜利 5 次 | 眠眠讲出它的心事：它一直在等星海里最老的灯「长明」回来。灯婆婆沉默了 |
| 真结局 | 集齐 12 封信 + 在浊深 5 胜利 | 灯婆婆说出自己是长明的一点火星；灰灰其实是长明掉下来的一小片疲倦。灰灰飞起来，变成一颗小小的新星挂在小院旁边。灯婆婆：「人间有味是清欢。」（苏轼《浣溪沙》） |

真结局之后，以后扩展的新星球（雾湾星、炉烟星……）作为「长明的路」解锁。

## 4. 文案风格

### 4.1 原则
1. **短**：一句话不超过 20 个字，一段话不超过 3 句。
2. **具体**：写看得见、听得见的东西（「湖边冒出一个小泡泡」），少写形容词。
3. **轻**：没有生死，没有仇恨，没有坏人。困难是「累了」「迷路了」「睡得太沉」。
4. **小妖说话**：每个系列一个口癖或语气。例如滴答句尾带「嗒」，苔团说话很慢、喜欢用叠词。

### 4.2 用词对照

| 不用 | 改用 |
|---|---|
| 杀、击杀、打死 | 打散（浊）、洗净（浊化小妖） |
| 死亡、阵亡 | 睡着 |
| 血、血量 | 体力（小妖）、心灯（心） |
| 怪物、敌人 | 浊、浊化小妖 |
| 捕捉、抓 | 结缘 |
| 进化 | 化形（小妖）、演化（星球） |
| 攻击力 | 力 |
| 失败、Game Over | 「心累了，再试一次吧」 |

### 4.3 文案示例

**落地文案**（沿用 demo，新增星鲸）

| 载具 | 文案 |
|---|---|
| 孔明灯 | 灯笼慢慢落低，光格一格一格亮起来。 |
| 油纸伞 | 伞慢慢落地，野餐布一格一格铺开。 |
| 雨云 | 下雨了……雨把灰洗掉，石板一块块露出来。 |
| 蒲公英 | 种子落下来，钻进土里……一畦一畦冒出绿芽。 |
| 小浮岛 | 小浮岛慢慢落下来，咚——稳稳落地。 |
| 星鲸 | 星鲸低低地游过，地上留下一圈亮晶晶的水痕。 |

**星相演化**

| 星相 | 文案 |
|---|---|
| 初醒 | 起风了。云开始走了。 |
| 萌青 | 灰底下，冒出一点点绿。 |
| 繁茂 | 下了一场好大的雨。林子长出来了。 |
| 生灵 | 远处有小妖在搬家，一队一队的。 |
| 清欢 | 星心醒了。这颗星，亮了。 |

**结缘**

| 情况 | 文案 |
|---|---|
| 成功 | 滴答跳起来转了一圈。「嗒！一起走嗒！」 |
| 失败 | 滴答吃完了，害羞地跑开了。以后在水边还能见到它。 |
| 栖地来访 | 湖岸来了一只咕噜，好像想要点水草团。 |

**图鉴**（滴答）
> 清晨挂在苔上的一滴露水，被风吹了一下，就醒了。走路的时候会「嗒、嗒」地响。很怕热，看到灯芯会躲到苔团后面。

**灯婆婆的教学**（第一场布阵）
> 看见那条暗紫色的路没有？浊会顺着它来。
> 苔团皮厚，放在来浊会经过的地方。滴答照看它身边的空地，守住心。
> 不急，摆好了再开始。
