# 05 小妖：结缘、成长、传承（单星肉鸽版）

> 肉鸽版把养成分成两半：**局内成长**（等级、化形、合流，每局清零）和**局外养成**（种类的羁绊等级、传承小妖，永久保留）。
> 旧版的亲密、心情、住处、劳作、安家已归档到 [future/](future/)。

## 1. 数据模型

### 1.1 种类（图鉴里的一页）

| 字段 | 说明 |
|---|---|
| 系列 | 同一条化形线，例如「滴答 → 涟涟 → 潮音」 |
| 形态 | 幼 / 成 / 灵（「产」系列只有幼、成） |
| 属性 | 水、暖、苔、光、汽、石之一；配育专属小妖有两个属性 |
| 定位 | 拦、射、溅、控、援、产之一 |
| 稀有度 | 常见、少见、稀有、珍稀 |
| 基础数值、普攻、主技、特性、相邻效果、光源 | 见 [data/小妖图鉴](data/小妖图鉴.md) |
| 喜欢的心意 | 结缘时送对了加成更高 |
| 出没地形 | 在什么地形、什么时辰、什么星相下出现（决定浊化群和蛋的种类） |
| 蛋群 | 第二阶段配育用 |

### 1.2 局内个体（这一局的队友，局末清零）

| 字段 | 说明 |
|---|---|
| 等级 | 1–20 |
| 形态 | 幼 / 成 / 灵 |
| 星级 | 1–3 星（合流得来） |
| 资质 | 体、力、灵三项，各 1–5 星 |
| 天赋 | 0–2 个 |
| 来源 | 开局、传承、结缘、蛋 |

### 1.3 传承小妖（局外，永久）
从某一局带回来的个体。保留：种类、天赋（1 个；羁绊 5 级时 2 个）、资质、异色、来历（例如「第 12 局，第 3 天的雨夜结缘」）。不保留等级、形态、星级。

## 2. 结缘（局内）

### 2.1 途径

| 途径 | 对象 | 基础结缘率 |
|---|---|---|
| 守心战 | 混在波次里的浊化小妖（迷途特征等） | 按稀有度：常见 60%、少见 45%、稀有 30%、珍稀 15% |
| 结缘战 | 浊化群里所有洗净的小妖 | 同上 |
| 泉主战 | 泉主（浊化的灵形） | 30% |
| 奇遇 | 「迷路的小妖」等事件 | 送对心意必定成功 |
| 蛋 | 收获三选一、行商 | 直接加入 |

### 2.2 结缘率加成（相加，上限 95%）

| 条件 | 加成 |
|---|---|
| 送一份露糖 | +10% |
| 送它喜欢的心意 | +25% |
| 场上有同属性的小妖 | 每只 +5%，最多 +15% |
| 温柔胜利（见 [04](04_战斗.md) 第 12.2 节） | +10% |
| 载具油纸伞 | +10% |
| 心灯之树「温柔」 | 每级 +5% |
| 浊深 7 以上 | −10% |

- 每只最多送 2 份心意，送了就消耗。成功率在送之前就显示。
- **失败**：它害羞地走开。这一局里，之后的浊化群有更高几率再遇到它，并且结缘率 +20%。
- 队伍已满 8 只时，结缘成功要先选一只「放走」（或者合流，见第 3.3 节）。

## 3. 局内成长

### 3.1 等级
- 1–20 级。从 L 级升到 L+1 级需要 30 × L 经验。
- 体和力 × (1 + 0.05 × (等级 − 1))。
- 经验来源：战斗（守心 100、结缘战 80、泉主 200，出场的每只都拿满，备战席拿一半）；喂一份心意 +60；露泉「全队 +1 级」；行商「练习」。

### 3.2 化形

| 化形 | 条件 | 倍率（体、力） |
|---|---|---|
| 幼 → 成 | 等级 ≥ 6 | ×1.6，射程 +0.1，主技 ×1.25 |
| 成 → 灵 | 等级 ≥ 12，且星相 ≥ 萌青 | ×2.4，射程 +0.2，主技 ×1.6 并有额外变化 |

- 条件满足时，小妖头上冒出一颗小星，在队伍界面点「化形」就化形（也可以不化）。
- 露泉的「立刻化形」无视等级条件，但不能跳过星相条件。
- **分支灵形**：该种类羁绊 4 级以后，化成灵形时可以在两种里选（例如滴答 → 潮音或霜铃；分支列表见 [data/小妖图鉴](data/小妖图鉴.md)）。旧版里「在某个栖地安家过一天」之类的条件在肉鸽版里全部改为「羁绊 4 级后自由选择」。

### 3.3 合流
- 结缘到一只**队伍里已经有的种类**时，可以选「合流」：两只合成一只，**星级 +1**（最多 3 星，每星体和力 +15%），等级取两者较高的再 +2，天赋取两者的并集（最多 2 个，超出时自己选）。
- 这是一点自走棋的味道：同一种小妖凑多了会变强，鼓励玩家围绕几个种类组队。

### 3.4 资质和天赋
- **资质**：结缘或孵化时随机：常见 1–3 星、少见 1–4、稀有 2–4、珍稀和泉主 3–5。每星 +4%（「灵」资质加主技效果）。传承小妖保留资质。
- **天赋**：结缘或孵化时 50% 有 1 个（羁绊 3 级的种类改为二选一）。24 个天赋见 [data/道具_天赋_星签](data/道具_天赋_星签.md)。
- 星签和奇遇也可能给天赋。

### 3.5 技能结构
每只小妖在战斗里有：普攻（由定位决定）、主技（灵力满自动放，灵形强化）、相邻效果（对上下左右相邻的队友，一直有）、特性（成形以后）、光源（部分种类）。

## 4. 局外养成

### 4.1 羁绊等级
每个种类一个，1–5 级，规则见 [07](07_一局的结构与局外成长.md) 第 8.2 节。小结：
- 1 级：可以作为开局小妖；
- 2 级：开局从 2 级开始；
- 3 级：天赋二选一；
- 4 级：分支灵形；
- 5 级：异色可选，传承时多保留 1 个天赋。

羁绊点来自：本局结缘过 +1；局末在队伍里 +1（胜利 +2）。

### 4.2 传承
- 局末从队伍里选 1 只（胜利 2 只）带回小院。传承栏最多 6 只。
- 下一局可以带 1 只传承小妖出发（心灯之树最多 3 只），从 1 级幼形开始，但带着它的天赋和资质。
- 小院里可以看、可以摸（播放开心动画）、可以放走。
- **这是肉鸽版的「养殖」**：玩家会一局一局地把同一只喜欢的小妖带回来，并通过它在局里遇到的星签、奇遇、合流，慢慢攒出更好的天赋和资质（局末带回时，局里得到的天赋可以替换掉原来的）。

### 4.3 图鉴
- 小院的石桌。每个种类一页：见过的显示样子和出没地形；结缘过的显示全部资料、羁绊等级和一段小故事。
- 收集奖励：结缘 10 种 → 解锁奇遇「小妖合影」；20 种 → 心灯之树多一个节点「图鉴之光」（每局开局心意 +2）；36 种 → 星鲸载具。

## 5. 第二阶段：配育

首发先不做配育，但保留设计，等传承系统跑起来以后加：

- 在小院把两只传承小妖放进暖窝，**下一局结束时**得到一个蛋，孵出新的传承小妖。
- 孩子的种类：从双亲两个系列里选；双亲符合配方时，可以选配育专属小妖。
- 继承：资质每项 50% 取较高、50% 取平均，15% 再 +1 星；天赋从双亲的天赋里选（双亲有相同天赋时可以选升阶版）。
- 双亲不会消失。

### 5.1 八个蛋群

| 蛋群 | 包含（举例） |
|---|---|
| 团子 | 滴答、姜姜、包包 |
| 毛团 | 松松、烘烘 |
| 壳岩 | 壳壳、亮壳、栗栗、墩墩、簇簇、圆圆、晶晶 |
| 鳞 | 咕噜 |
| 羽 | 扑扑、鸢鸢、砾砾 |
| 灵器 | 瓢瓢、炉炉、擦擦、灯芯、镜镜、茶烟、叮叮 |
| 菌苔 | 苔团、菇菇、绕绕、芽芽、豆豆 |
| 灵体 | 浮浮、露宝、萤子、闪闪、晴晴、绵绵、旋旋、沙沙（可以和任何群配育） |

### 5.2 配育专属小妖
6 种，只能配育得到，**双属性**：同时算两种属性的羁绊；攻击时取对目标更有利的克制倍率；被攻击时一律 ×1.0。

| 小妖 | 属性 | 定位 | 配方（双亲系列） |
|---|---|---|---|
| 汽泡 | 水 + 暖 | 溅 | 滴答系 × 灯芯系 |
| 青灯 | 苔 + 光 | 援 | 苔团系 × 萤子系 |
| 雪团子 | 水 + 汽 | 控 | 浮浮系 × 绵绵系 |
| 熔岩龟 | 暖 + 石 | 拦 | 炉炉系 × 墩墩系 |
| 苔絮 | 苔 + 汽 | 产 | 豆豆系 × 叮叮系 |
| 星砂鱼 | 光 + 石 | 射 | 闪闪系 × 晶晶系 |

## 6. 队伍（局内）

- 一局里队伍最多 8 只。
- 战斗时：开局免费出阵的数量和备战席数量随星相增长（见 [04](04_战斗.md) 第 8.5 节），其余留在后方不参战，拿一半经验。
- 队伍界面（任何时候在星球视图按 Y 打开）：看等级和形态、化形、喂心意、调整出阵和备战、放走。
