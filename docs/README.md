# 清欢小星设计交接文档

版本：v3.1 纯文字交接版，2026-10-22。基于用户最新上传的 v3 文档修订；不是重新发明世界观。本包没有图片、截图、参考 HTML、美术素材或外部画风链接。

## 当前要做什么

下一位 AI 要做两个完整、独立、离线的 HTML 原型，让设计者比较像素风与彩色线条插画风。两版必须有同样的星球选择、转场、自由布阵、自动战斗、真实胜败、结算和回星进度；不是只做棋盘，也不是十种风格画廊。此文档包本身只交付需求，不包含新实现，不表示旧画面已经通过验收。

## 已确认方向

- 苔眠星是可全向 360° 旋转的立体球体，正面、背面、两极都能看到并选择落点；它只承担世界探索、选地和演化展示，不在球面上布阵作战。
- 正式战斗进入独立 HD-2D 场景：固定斜俯视、方格地形有厚度与适量高差，角色和装饰以二维美术表现。不能把小妖改成圆球、胶囊或完整三维建模角色。
- 采用方案 A：自由方格布阵、中心守心、多方向入口、实时寻路。自由指可在所有合法空格部署，不等于没有网格；没有固定蛇形道路、指定车道或“路上仅拦能站”的限制。
- 保留清欢的温柔气质、浊与净化、滴答/苔团/灯芯等原有小妖及定位。不把其他样例的内容、场景、物种和布局搬进来，也不另创一套生物替换原设定。
- 像素版和线条版是同一游戏的两种完整美术处理，只有美术表现不同，玩法、构图、地图种子、单位、数值与镜头相同。
- 动作必须有局部变化、预备、发力和回收；禁止让所有角色仅靠整张图上下浮动、缩放、摇摆冒充动画。

## 保留的完整游戏概念

一局来到随机生成的苔眠星，在球体上选落点，进入相应地貌的沙盘布阵、自动守心、洗净小妖并结缘。胜利使沙盘及星球对应区域清亮，队伍成长、星相演化；封泉、唤醒星心后回小院。失败不会表现为伙伴死亡。完整游戏的局内露水、局外星砂、传承、养育等仍见原主题文档。

当前 HTML 的“完整”指选地到回星的完整可玩小循环，不是首发全部 36 系列和长线养成。

## 关键术语

- 星球格：362 格球面的区域单元，仅世界地图使用，含 12 个五边格。
- 战场格：独立的平面方格，用于放置、寻路与射程计算；与星球格不是同一套坐标。
- 心：战场中心的守护目标；心灯是生命值。
- 动态路线：依地形和当前阵型实时计算的敌人行进结果，不是地图里的预铺道路。
- 清亮度：已净化陆地格占全部陆地格的比例；回星后来自真实结算，不能只变一行数字。

## 未确认而采用的默认

11×7、俯角约 40°、像素内部画面 480×270、本次三个边界入口、测试数值等是便于原型的默认值，不等同于最终美术批准。线条的具体笔触、原创造型细节、装饰密度由新实现者在文字规范内设计，最终由用户选择。后续 Godot 版本以用户本地目标 4.7.2 为移植目标；本包不声称已安装、运行或验证该版本。
