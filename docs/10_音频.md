# 10 音频

## 1. 方向

- **清、轻、暖**：声音帮玩家知道「这一下生效了」，并陪着玩家慢慢看星球。没有尖叫、警笛、爆炸、刺耳的方波。
- **民乐音色 + 柔和芯片音**：古筝、琵琶、笛、箫、二胡、木鱼、梆子、编钟，加上经过低通的正弦波、三角波。
- **全部由代码合成**：和美术一样，声音也是数据。原资料已经有一个确定性的小型合成器和民乐音色预设（`audio/presets.json`：guzheng、pipa、dizi、xiao、erhu、muyu、bangzi、bianzhong……），我们沿用这种做法，自己写音色和曲子。
- 合成在**构建时**完成，导出 WAV/OGG 进游戏；运行时不实时合成（省 CPU，也保证每台机器听到的一样）。

> 授权提醒：原资料的**合成器代码**是 MIT，可以借用；它导出的**声音文件**是 CC BY-NC-SA，不能用。我们的音色参数和曲子要自己做。

## 2. 随星相生长的配乐

这是音频最重要的设计：**星球演化，音乐也跟着「长」出来**（Terra Nil 的配乐会随玩家的操作变化，这里借鉴的是这个思路）。

### 2.1 星球主题曲的分层
苔眠星有一首主题曲（宫调式，笛子主奏），写成 5 个声部，同调、同速、同长度，可以任意叠加。**每一局开始都只有第一个声部**，星相每升一档加一个声部，所以每一局都能听到音乐从空到满「长」一遍。

| 星相 | 加入的声部 | 听感 |
|---|---|---|
| 灰寂 | 箫的长音（低、慢、稀疏） | 空、安静 |
| 初醒 | 古筝的分解和弦 | 有了一点动静 |
| 萌青 | 笛子的主旋律 | 有了歌 |
| 繁茂 | 琵琶节奏和木鱼 | 热闹起来 |
| 清欢（胜利） | 二胡副旋律和编钟，全部声部 | 完整的一首歌，只在胜利演出时完整听到 |

- 星相演化演出时，新声部在下一小节的开头淡入（2 小节）。
- 每天的浊潮结算时，所有声部压低 6 dB 两小节，加一个低沉的长音，然后恢复。
- 以后扩展新星球时，每颗星换调式和主奏乐器（雾湾星羽调式、箫；炉烟星徵调式、琵琶……）。

### 2.2 战斗
- 战斗音乐 = 当前星球主题曲 + 一个**战斗层**（更密的木鱼和梆子节奏、低音）。同调同速，所以落地时可以无缝切换。
- 第三波和首领的第二阶段再加一个**紧张层**（二胡颤音）。
- 胜利：三音的温暖收束，然后战斗层淡出，回到主题曲。

### 2.3 时辰
- 夜里：主题曲整体低通（截止约 1800 Hz），笛子换成箫，速度不变。
- 雨天：加一层轻的雨声环境音，音乐音量 −2 dB。

### 2.4 小院
- 小院有自己的主题：古筝和木鱼，很慢。
- 心灯之树每买一项升级，主题里多一个小装饰音（例如风铃声），最多 6 个。
- 一局失败回到小院时，先放 4 小节只有箫的版本，再慢慢回到完整的小院主题。

## 3. 规格

沿用原资料的可测量标准（它的 `docs/design/audio.md` 写得很完整），略作调整：

| 项目 | 规格 |
|---|---|
| 文件 | 44,100 Hz、单声道、16-bit；音乐导出 OGG，音效导出 WAV |
| 音高 | 有音高的声部基频 65–1760 Hz；低通截止不超过 4000 Hz |
| 包络 | 起音 ≥ 8 毫秒，释音 ≥ 25 毫秒；不硬切 |
| 音效响度 | 有声段 RMS −24 ± 2 dBFS |
| 音乐响度 | 一个完整循环 RMS −26 ± 2 dBFS |
| 峰值 | ≤ −9 dBFS，不削波 |
| 音乐节奏 | 60–100 BPM，4/4 拍，每首 32 小节 |
| 循环接缝 | 首尾采样差 ≤ 0.002；连续听 3 圈没有爆音 |
| 噪声 | 音效里噪声成分不超过 8%；环境音（雨、风）例外，但要低通 |

## 5. 小妖的叫声

约 120 种形态不可能一一做，所以用**模板加参数**生成：

| 参数 | 由什么决定 |
|---|---|
| 音高 | 形态：幼高、成中、灵低（各差约一个五度） |
| 音色 | 属性：水是带滑音的正弦，暖是噼啪的拨弦，苔是软木块，光是铃，汽是气声，石是低闷的敲击 |
| 节奏 | 系列：每个系列 2–3 个音的固定节奏型（例如滴答是「嗒、嗒」两下） |
| 情绪 | 动作：开心时上行，睡着时下行，结缘成功时多一个音 |

每个系列只需要写一行节奏型，其余自动组合。

## 6. 环境声

| 环境 | 做法 |
|---|---|
| 风 | 低通噪声，音量随风天和高度变化 |
| 雨 | 噪声加随机水滴，雨天才有 |
| 海浪 | 低通噪声的慢速起伏（雾湾星） |
| 篝火、温泉 | 噼啪声和咕嘟声（炉烟星） |
| 生灵 | 生灵星相以后，偶尔的鸟叫、虫鸣（都用小妖叫声的模板） |

环境声跟镜头：整星视图时很轻，近景时变响。

## 7. 混音

| 总线 | 内容 | 默认音量 |
|---|---|---|
| 音乐 | 主题曲和战斗层 | 70% |
| 音效 | 战斗、星球、小院 | 80% |
| 环境 | 风雨浪 | 60% |
| 叫声 | 小妖 | 80% |
| 界面 | UI | 60% |

- 结缘成功、星相演化、化形这三个时刻，音乐压低 4 dB，让主角声音出来。
- 2× 和 3× 速度时，同类命中音效的上限减半，避免太吵。
- 设置里可以分别调五条总线；有「单声道」选项。
