# 05 小妖：结缘、养育、化形、配育、安家

## 1. 数据模型

分成「种类」（图鉴里的一页，所有个体共用）和「个体」（玩家拥有的那一只）。

### 1.1 种类（Species）

| 字段 | 说明 |
|---|---|
| 系列 | 同一条化形线的小妖属于一个系列，例如「滴答 → 涟涟 → 潮音」 |
| 形态 | 幼 / 成 / 灵 |
| 属性 | 水、暖、苔、光、汽、石之一；配育专属小妖有两个属性 |
| 定位 | 拦、射、溅、控、援、产之一 |
| 稀有度 | 常见、少见、稀有、珍稀 |
| 基础数值 | 在定位模板上的浮动（见 [04](../04_战斗.md) 第 4.2 节） |
| 主技 | 灵力满时放的技能。灵形是强化版 |
| 特性 | 成形解锁的被动 |
| 相邻效果 | 对相邻队友的效果 |
| 劳作 | 1–2 种适性，各 1–3 级 |
| 蛋群 | 决定和谁能配育，共 8 群 |
| 喜好 | 喜欢的心意类别，以及喜欢的栖地 |
| 出没 | 哪颗星、哪种栖地，什么时辰和天气 |
| 化形条件 | 见第 4 节 |

### 1.2 个体（Individual）

| 字段 | 说明 |
|---|---|
| 昵称 | 默认是种类名，可以改 |
| 等级、经验 | 1–40 |
| 亲密 | 0–100，显示为 5 颗心 |
| 心情 | 开心 / 普通 / 没精神 |
| 资质 | 体、力、灵三项，各 1–5 星 |
| 天赋 | 0–2 个，从 24 个里来（见 [data/道具_天赋_星签](../data/道具_天赋_星签.md)） |
| 传承 | 0–1 个，配育时从双亲的特性里继承 |
| 最爱 | 这一只最爱的一种心意（从种类的喜好里随机定一个） |
| 异色 | 是否异色（调色板换色） |
| 来历 | 在哪颗星、哪种方式结缘的，记一句话，例如「在雾湾星的雨夜，浅滩」 |
| 状态 | 在星屿 / 在队伍 / 安家在某个栖地 / 在暖窝 |

## 2. 结缘

### 2.1 三条途径

| 途径 | 对象 | 基础结缘率 |
|---|---|---|
| **战后结缘** | 守心战或结缘战里洗净的浊化小妖 | 按稀有度：常见 60%、少见 45%、稀有 30%、珍稀 15% |
| **栖地结缘** | 栖地里来访的野妖（没有浊化） | 上面的数 +15% |
| **首领结缘** | 泉主 30%；星心在「清欢」剧情后自动结缘 | — |

另外，收获三选一和配育会给**蛋**，孵出来直接是自己的小妖。

### 2.2 结缘率加成（相加，上限 95%）

| 条件 | 加成 |
|---|---|
| 送一份普通心意 | +10% |
| 送它喜欢的那一类心意 | +25% |
| 送它最爱的那一种 | +40% |
| 场上有同属性的小妖 | 每只 +5%，最多 +15% |
| 温柔胜利（见 [04](../04_战斗.md) 第 12.2 节） | +10% |
| 它比你队伍平均等级高 | 每高 1 级 −3% |
| 挑战难度 | −10% |

- 每只最多送 2 份心意，送了就消耗。成功率在送之前就显示出来。
- 心意的种类和做法见 [06](星屿家园_长线版_未来扩展.md) 第 4 节。

### 2.3 失败了会怎样
- 它醒过来，有点害羞地走开，在星球上变成「游荡野妖」，3 天内在清亮的地上走来走去。
- 之后如果有符合它喜好的栖地，它会优先来访，并且结缘率再 +20%。
- **永远不会错过任何一只小妖**，包括泉主（泉主失败后会住进离浊泉最近的栖地）。

### 2.4 栖地结缘的流程
1. 星球视图上，栖地里来访的野妖头上有一个小气泡，显示它想要什么（一种心意的图标）。
2. 点它，镜头拉到中景，弹出结缘小窗：显示成功率，选心意送它。
3. 成功：它跳起来转一圈，飞向星屿。失败：它吃了东西，满意地走开，下一天大概率还会再来（结缘率 +10%）。

### 2.5 重复和放归
- 同一种小妖可以有多只，配育要用。
- **放归**：把一只小妖放回星球。它会安家在最适合它的栖地（见第 8 节），不再占星屿的窝位，以后也可以接回来。
- 没有「卖掉」或「分解」小妖的功能。

## 3. 养育

### 3.1 住处
- 星屿的窝位：初始 8 个，每级小妖屋 +4，最多 40 个。
- 窝位满了，新结缘的小妖进「云上寄存」：数量不限，但不干活、不涨亲密。
- 第三个办法：放到星球上安家（第 8 节）。

### 3.2 亲密
0–100，每 20 点一颗心。

| 怎么涨 | 每次 |
|---|---|
| 喂一份普通心意（每只每天 1 次） | +5 |
| 喂它喜欢的那一类 | +10 |
| 喂它最爱的那一种 | +15 |
| 摸一摸（在星屿小院里点它，每天 1 次） | +2 |
| 参加一场胜利的战斗 | +2 |
| 心情开心时干一天活 | +1 |

| 亲密 | 效果 |
|---|---|
| 2 颗心（40） | 可以化形成「成」 |
| 3 颗心（60） | 在星屿里会跟着主角走；战斗开场灵力 +10 |
| 4 颗心（80） | 可以化形成「灵」 |
| 5 颗心（100） | 解锁一句专属的话；战斗中第一次要睡着时，留 1 点体力撑住（每场一次） |

### 3.3 心情

| 心情 | 怎么来 | 效果 |
|---|---|---|
| 开心 | 当天吃过东西、窝附近有它喜欢的摆件、没有连续干 3 天以上的活 | 劳作 +20%；战斗开场灵力 +10 |
| 普通 | 其他情况 | — |
| 没精神 | 连续 2 天没吃东西，或连续干活 4 天 | 劳作 −30%；不涨亲密 |

心情不会影响战斗胜负，只影响一点点效率。目的是让玩家愿意每天看一眼小院，而不是惩罚。

### 3.4 经验和等级
- 等级上限：幼 15，成 30，灵 40。到上限后经验会存起来，化形后立刻补上。
- 经验来源：
  - 战斗：出过场的小妖平分（守心战 = 30 × 星球序号，泉主战 ×2）；没出场的备战席小妖拿一半。
  - 星屿「练习场」：每天给 3 只小妖各 20 × 星球序号。
  - 「经验果」：心意的一种，直接给经验。
- 经验曲线：升到 L 级累计需要 10 × L²（升到 40 级需要 16000）。

## 4. 化形

### 4.1 条件

| 化形 | 共同条件 | 系列条件 |
|---|---|---|
| 幼 → 成 | 等级 ≥ 12，亲密 ≥ 40 | 无 |
| 成 → 灵 | 等级 ≥ 26，亲密 ≥ 80 | 每个系列一个（见下表和图鉴） |

### 4.2 系列条件的种类

| 种类 | 例子 |
|---|---|
| 道具 | 灯芯 → 灯盏 → 走马灯：要一份「灯油」 |
| 时辰 | 萤火 → 萤河：要在夜里化形 |
| 栖地 | 在「雪原」栖地安家过一天的涟涟 → 霜铃 |
| 天气 | 风团 → 回风：在风天化形 |
| 星相 | 某些系列要求所在星球达到「生灵」 |
| 战斗 | 在一场有 3 只以上石属性的战斗里赢过 |

### 4.3 分支
有 6 个系列的灵形有两种，由条件决定。例如：

| 系列 | 普通灵形 | 分支灵形 | 分支条件 |
|---|---|---|---|
| 滴答 | 潮音（水·射，连射） | 霜铃（水·射，冻结） | 在雪原栖地安家过一天 |
| 苔团 | 苔丘（苔·拦，更厚） | 苔亭（苔·援，能治疗） | 亲密 100 时在晨化形 |
| 灯芯 | 走马灯（暖·溅，绕圈火团） | 孔明（暖·射，追踪火团） | 带着孔明灯载具赢过 20 场 |
| 茶烟 | 云雾（汽·控，大范围睡） | 茶仙（汽·援，治疗加速） | 在小茶棚栖地安家过一天 |
| 萤子 | 萤河（光·射，长链） | 萤灯（光·拦，会发光的拦） | 在长明星化形 |
| 墩墩 | 石敢当（石·拦，定身） | 石狮（石·溅，震地） | 赢一场 4 只以上石属性的战斗 |

分支会改定位，所以同一个系列能在队伍里扮演不同角色。

### 4.4 化形的操作
- 条件满足后，小妖头上冒出一颗小星星。玩家在小妖册里点「化形」才会化形。可以一直不化（喜欢幼形的样子也没问题）。
- 演出：小妖发光，像素一块块溶解重组成新形态，约 3 秒。

## 5. 资质与天赋

### 5.1 资质
- 体、力、灵三项，各 1–5 星，每颗星 +4%。
- 结缘时随机：常见 1–3 星，少见 1–4，稀有 2–4，珍稀和泉主 3–5。
- 只能靠配育提高（第 7 节）。

### 5.2 天赋
- 每只 0–2 个，共 24 个，例如：

| 天赋 | 效果 | 升阶版（双亲都有时可继承） |
|---|---|---|
| 早起 | 开场灵力 +30 | 晨光：开场灵力 +50，并给相邻队友 +15 |
| 恋家 | 劳作效率 +20% | 守家：劳作 +35%，心情不会变差 |
| 胆小 | 没有相邻敌人时力 +15% | 慎行：没有相邻敌人时力 +25%，射程 +0.2 |
| 贪吃 | 喂食亲密 ×2，劳作 −10% | 好胃口：喂食亲密 ×2，没有减益 |
| 夜猫 | 夜里力 +20% | 夜游：夜里力 +30%，自带半径 0.5 的光 |

完整 24 个见 [data/道具_天赋_星签](../data/道具_天赋_星签.md)。

- 结缘时：60% 有 1 个，15% 有 2 个，25% 没有。

## 6. 技能结构

每只小妖在战斗里有 4–5 样东西，都可以在详情页看到：

| 项 | 什么时候有 | 说明 |
|---|---|---|
| 普攻 | 一直 | 由定位决定 |
| 主技 | 一直；灵形强化 | 灵力满自动放 |
| 相邻效果 | 一直 | 对相邻队友 |
| 特性 | 成形以后 | 种类固定的被动 |
| 传承 | 配育得来 | 双亲之一的特性，跨系列也可以 |

「传承」是配育最有趣的地方：例如让苔团继承萤子的特性「引萤」（自带 1 格的光），得到一只能在夜里照亮路的拦。

另外，有些小妖天生是**光源**（灯芯、萤子、亮壳等，见图鉴的「光」一列），夜战里它们周围的格子是亮的。

## 7. 配育

### 7.1 基本规则
- 在星屿的**暖窝**里进行。暖窝 1 级能放 1 对，2 级 2 对，3 级 3 对。
- 双亲：两只成形或灵形的小妖，蛋群相同。**灵体群可以和任何群配育**（它们像风一样，跟谁都合得来）。
- 不区分性别。
- 时间：2 天（8 个时辰）生一个蛋。暖窝里派一只「生火」适性的小妖，时间缩短：生火 2 级 1.5 天，3 级 1 天。
- 双亲不会消失。配育完会累一天（不干活）。

### 7.2 八个蛋群

| 蛋群 | 包含（举例） |
|---|---|
| 团子 | 滴答、姜姜、包包 |
| 毛团 | 松松、烘烘 |
| 壳岩 | 壳壳、亮壳、栗栗、墩墩、簇簇、圆圆、晶晶 |
| 鳞 | 咕噜 |
| 羽 | 扑扑、鸢鸢、砾砾 |
| 灵器 | 瓢瓢、炉炉、擦擦、灯芯、镜镜、茶烟、叮叮 |
| 菌苔 | 苔团、菇菇、绕绕、芽芽、豆豆 |
| 灵体 | 浮浮、露宝、萤子、闪闪、晴晴、绵绵、旋旋、沙沙（可以和任何群配育） |

每个系列所在的蛋群见图鉴。

### 7.3 孩子是什么
- **玩家自己选**：从双亲两个系列的幼形里选一个。
- 如果双亲是某个**配育专属小妖**的配方，第三个选项就是它（第 7.5 节）。

### 7.4 继承什么

| 项 | 规则 |
|---|---|
| 资质 | 每一项：50% 取双亲中较高的，50% 取平均（向下取整）；然后 15% 几率再 +1 星（最多 5）。用道具「同心结」可以保证取较高的 |
| 天赋 | 从双亲所有天赋里**选**最多 2 个。双亲有相同天赋时，可以选它的升阶版 |
| 传承 | 从双亲的**特性**里选 1 个（双亲必须是成形以上） |
| 亲密 | 孩子出生就有 40（2 颗心） |
| 异色 | 基础 1/64；双亲都是异色 1/8；在「清欢」星相的星球旁边配育 1/32 |

**蛋的孵化**：放在暖窝里 1 天孵化；或者带在队伍的备战席里，打 3 场战斗后孵化。

### 7.5 配育专属小妖
6 种，只能配育得到。它们是**双属性**：同时算两种属性的羁绊。攻击时取对目标更有利的克制倍率；被攻击时一律按 ×1.0 算（没有弱点也没有抗性）。

| 小妖 | 属性 | 定位 | 配方（双亲系列） | 附加条件 |
|---|---|---|---|---|
| 汽泡 | 水 + 暖 | 溅 | 滴答系 × 灯芯系 | 其中一方是灵形 |
| 青灯 | 苔 + 光 | 援 | 苔团系 × 萤子系 | 在夜里生蛋 |
| 雪团子 | 水 + 汽 | 控 | 浮浮系 × 绵绵系 | 雪眠星旁边 |
| 熔岩龟 | 暖 + 石 | 拦 | 炉炉系 × 墩墩系 | 炉烟星旁边 |
| 苔絮 | 苔 + 汽 | 产 | 豆豆系 × 叮叮系 | 风天 |
| 星砂鱼 | 光 + 石 | 射 | 闪闪系 × 晶晶系 | 双亲都是灵形 |

图鉴里它们的那一页一开始是剪影，只写一句提示，例如汽泡：「好像是一滴水和一点火，在暖窝里吵了一架」。

## 8. 安家

把小妖放回星球生活，是养育和星球演化之间的桥。

- **操作**：在小妖册里选一只 → 选一颗星上的一个栖地 → 它住进去。
- **效果**：
  - 星球生机 +3（幼）/ +5（成）/ +8（灵）；住的是它喜欢的栖地时 ×2；
  - 栖地每天的材料产出 +1 份；
  - 同蛋群的野妖来访几率 +20%；
  - 「安家伙伴」：在它的栖地 2 格内打的战斗，它会免费上场帮忙（见 [03](../03_星球与演化.md) 第 4.4 节）。
- 安家的小妖不占星屿窝位，每天亲密 +1、经验 +5 × 星球序号。
- 在那颗星上时，随时可以接回星屿。
- 每个栖地最多住 2 只安家小妖。

## 9. 小妖册与图鉴

### 9.1 小妖册（自己的小妖）
- 列表：可以按属性、定位、等级、亲密、状态筛选和排序。
- 详情页：像素立绘（放大 4 倍）、数值、资质星、天赋、技能四件套、亲密、心情、来历、化形条件。
- 操作：改昵称、喂食、化形、加入队伍、放进暖窝、安家、放归。

### 9.2 图鉴
- 每个种类一页：见过的显示样子和出没提示；结缘过的显示全部资料和一段小故事（2–3 句）。
- 化形条件：见过灵形之前只显示「？？？」和一句提示。
- 完成奖励：

| 结缘种类数 | 奖励 |
|---|---|
| 10 | 星屿摆件「小妖合影」 |
| 20 | 心意「星糖」×3（结缘率 +40%，任何小妖都喜欢） |
| 36 | 36 个基础系列全部结缘 → 隐藏载具「星鲸」 |
| 全部（含配育专属和星心） | 星屿换上「清欢」的配色；结局后多一段话 |

## 10. 队伍

- 队伍 = 开局免费出阵的小妖 + 备战席的小妖，数量由心灯等级决定（见 [04](../04_战斗.md) 第 8.5 节）。
- 星屿上的任何小妖都可以编进队伍；选地面板里也可以直接换人。
- 3 套**队伍预设**，可以命名（例如「夜战」「浊壳多」）。
- 安家的小妖不在队伍里，但会以「安家伙伴」的方式帮忙。

---

## 11. 劳作（摘要）

每只小妖有 1–2 种劳作适性，各 1–3 级。派它们去星屿的建筑干活，产出材料。详细规则见 [06](星屿家园_长线版_未来扩展.md) 第 3 节。

| 适性 | 干什么 | 典型小妖 |
|---|---|---|
| 浇灌 | 露井集露、浇苗圃 | 滴答、露宝、瓢瓢 |
| 生火 | 茶灶做心意、暖窝孵蛋 | 炉炉、灯芯、包包 |
| 培土 | 苗圃育种 | 苔团、芽芽、豆豆 |
| 采拾 | 果树、茶园、晶石采集 | 松松、栗栗、晶晶 |
| 搬运 | 把星球栖地的产出运回星屿 | 墩墩、亮壳、鸢鸢 |
| 点灯 | 灯坊做灯油、夜里照亮小院 | 萤子、扑扑、浮浮 |
