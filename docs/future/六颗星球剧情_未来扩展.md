# 08 世界观与剧情

## 1. 世界

### 1.1 星海与小星
- 夜空里漂着许多小星。每颗小星都有一位**星心**：星球自己的灵，可能是一只老龟、一头云鲸、一座会走的灶。
- 星心醒着的时候，星球上有风、有雨、有小妖。星心睡着了，星球就慢慢落满灰。

### 1.2 浊
- 浊不是坏东西，它是**累积下来的疲倦**。星心太累了，睡得太沉，做的梦就变成灰，一层层落在星球上。
- 浊会聚成一团团会动的东西（浊团、灰絮……），它们没有心，只是本能地往亮的地方走（所以会去碰「心」）。打散它们，它们就变回露水。
- 浊落在小妖身上，小妖就会迷糊、发脾气，这就是「浊化」。洗净以后，它们只会觉得睡了一个很长的午觉。

### 1.3 清星人
- 主角是一位**清星人**：在星海里旅行、替睡着的小星扫灰的人。
- 清星人不是战士。他们带着小妖，用灯、伞、雨云这些小东西落到星球上，在落脚的地方「点一个心」，让小妖守着它，等浊散开。
- 主角没有固定的性别和外形设定，开局可以选外观（3 种发型 × 4 种衣服配色），默认名字「阿青」，可以改。全文不用第三人称代词称呼主角。

### 1.4 星屿和灯婆婆
- 星屿是清星人的家，一块绕着星球转的小浮屿。
- 屿上的**心灯**里住着灯婆婆：一团说话慢悠悠的老火苗。她是导师，也是整个故事的讲述者。她知道很多星星的事，但不知道浊从哪里来。

### 1.5 灰灰
- 序章里，主角在星屿上发现一小团没散掉的浊。它不攻击，也不怕光，只是好奇地跟着主角。主角给它起名叫「灰灰」。
- 灰灰不能战斗，也不能结缘。它一直跟在主角身边，每清欢一颗星，它的颜色就淡一点。
- 灰灰是故事的暗线：它其实是最老的那盏灯「长明」掉下来的一小片疲倦。

## 3. 主线

每颗星的故事都很短，围绕一件小事。星心的心事就是这颗星的主题。

### 序章 · 星屿（约 3 分钟）
- 主角在星屿上醒来，灯婆婆说：「下面那颗星，睡得太沉啦。」
- 灰灰从角落里冒出来。
- 主角带着滴答、苔团、灯芯，第一次坐孔明灯落地。

### 第一章 · 苔眠星：「几点了」
- **主题**：醒来。
- **开头**：苔眠星灰得连湖都看不见。小妖们都在睡。
- **中段**：第一场雨后，湖边的茶烟们迷迷糊糊地发脾气（浊化）。洗净后，它们说「做了个很长的梦，梦里一直在等人叫醒」。
- **高潮**：眠眠背上长满了浊苔，它不是在攻击，是在翻身，想醒又醒不过来。
- **结尾**：眠眠醒来，第一句话：「几点了？」灯婆婆笑：「早着呢，慢慢来。」眠眠送主角一片苔，从此每颗星的阵地边都会长一点苔。

### 第二章 · 雾湾星：「有人在吗」
- **主题**：孤单和回声。
- **开头**：雾里总有歌声，听不清是谁在唱。
- **中段**：亮壳们说，那是汐汐在唱。汐汐每天游一圈，想找另一头鲸，可是星海里只有它一头。
- **高潮**：汐汐的潮水一次次淹过阵地，像在发脾气，其实是在哭。
- **结尾**：汐汐醒来，发现星屿上的小妖们在跟着它的歌哼。它说：「原来唱歌不一定要有另一头鲸听。」

### 第三章 · 炉烟星：「多吃一点」
- **主题**：照顾别人的人也需要被照顾。
- **开头**：梯田上的灶全都冷了，可是浊特别暖和，像刚熄的炉子。
- **中段**：姜姜和包包说，烘婆给全星的小妖做饭，做了几百年，从来没吃过一口热的。
- **高潮**：烘婆是一座会走的老灶，地热格喷出来的浊火，是它最后一点没烧完的力气。
- **结尾**：主角的小妖们一起给烘婆做了一顿饭（用玩家这一章做过的心意）。烘婆嘴上说「火候不对」，吃得一点不剩。

### 第四章 · 风絮星：「线还在吗」
- **主题**：放手和牵挂。
- **开头**：风很大，满天都是断了线的风筝。
- **中段**：叮叮说，大鹞想飞去星海另一头，又怕飞远了就回不来，所以一直在原地打转，把风搅乱了。
- **高潮**：大鹞在阵地上空盘旋，每次转向，风就换方向。
- **结尾**：主角把星屿的一根线系在大鹞脚上。大鹞说：「线还在就好。」它第一次飞到云上去，又自己飞了回来。

### 第五章 · 雪眠星：「别忘了」
- **主题**：记忆。
- **开头**：一片很安静的雪原，所有的脚印都被雪盖住了。
- **中段**：霜鹿记得每一片雪落下的样子，也记得每一个离开的小妖。它害怕忘记，所以不肯让雪化。
- **高潮**：霜鹿把路冻成冰，不让任何东西走过去。
- **结尾**：雪化了，雪下面是去年、前年、很多年前小妖们留下的东西（摆件）。霜鹿说：「原来化了也还在。」
- 这一章的结尾，灰灰几乎变白了。灯婆婆第一次露出担心的样子：「最后那颗星……是长明吧。」

### 第六章 · 长明星：「可以歇一歇」
- **主题**：休息。
- **开头**：永夜的星，到处是熄掉的灯台。灯婆婆说，她年轻时是长明的一点火星，后来被分出来，才有了星屿的心灯。
- **中段**：每点亮一座灯台，就能看到一段长明的记忆：它照亮了星海里每一颗星，一刻也没歇过。浊，就是它掉下来的疲倦，飘到各处的星上，让星心们也跟着困了。
- **高潮**：长明的光变成了浊，熄灭了整个阵地。五位星心一个个出现，各自点亮一小块。
- **结尾**：长明终于肯闭上眼睛歇一歇。六位星心约好，以后每颗星轮流亮一点，谁也不用一直亮着。灰灰飞起来，变成一颗很小很小的新星，挂在星屿旁边。

### 尾声
- 回到星屿，灯婆婆说出那句话：「人间有味是清欢。」（苏轼《浣溪沙》）
- 星图上六颗星都亮着，远处的浊海还是灰的。灯婆婆：「那边的星，就慢慢来吧。」→ 开放终局。

## 4. 文案风格

### 4.1 原则
1. **短**：一句话不超过 20 个字，一段话不超过 3 句。
2. **具体**：写看得见、听得见的东西（「湖边冒出一个小泡泡」），少写形容词。
3. **轻**：没有生死，没有仇恨，没有坏人。困难是「累了」「迷路了」「睡得太沉」。
4. **小妖说话**：每个系列一个口癖或语气。例如滴答句尾带「嗒」，苔团说话很慢、喜欢用叠词。

### 4.2 用词对照

| 不用 | 改用 |
|---|---|
| 杀、击杀、打死 | 打散（浊）、洗净（浊化小妖） |
| 死亡、阵亡 | 睡着 |
| 血、血量 | 体力（小妖）、心的体力（心） |
| 怪物、敌人 | 浊、浊化小妖 |
| 捕捉、抓 | 结缘 |
| 进化 | 化形（小妖）、演化（星球） |
| 攻击力 | 力 |
| 失败、Game Over | 「心累了，再试一次吧」 |

### 4.3 文案示例

**落地文案**（沿用 demo，新增星鲸）

| 载具 | 文案 |
|---|---|
| 孔明灯 | 灯笼慢慢落低，光格一格一格亮起来。 |
| 油纸伞 | 伞慢慢落地，野餐布一格一格铺开。 |
| 雨云 | 下雨了……雨把灰洗掉，石板一块块露出来。 |
| 蒲公英 | 种子落下来，钻进土里……一畦一畦冒出绿芽。 |
| 小浮岛 | 小浮岛慢慢落下来，咚——稳稳落地。 |
| 星鲸 | 星鲸低低地游过，地上留下一圈亮晶晶的水痕。 |

**星相演化**

| 星相 | 文案 |
|---|---|
| 初醒 | 起风了。云开始走了。 |
| 萌青 | 灰底下，冒出一点点绿。 |
| 繁茂 | 下了一场好大的雨。林子长出来了。 |
| 生灵 | 远处有小妖在搬家，一队一队的。 |
| 清欢 | 星心醒了。这颗星，亮了。 |

**结缘**

| 情况 | 文案 |
|---|---|
| 成功 | 滴答跳起来转了一圈。「嗒！一起走嗒！」 |
| 失败 | 滴答吃完了，害羞地跑开了。以后在水边还能见到它。 |
| 栖地来访 | 湖岸来了一只咕噜，好像想要点水草团。 |

**图鉴**（滴答）
> 清晨挂在苔上的一滴露水，被风吹了一下，就醒了。走路的时候会「嗒、嗒」地响。很怕热，看到灯芯会躲到苔团后面。

**灯婆婆的教学**（第一场布阵）
> 看见那条暗紫色的路没有？浊会顺着它来。
> 苔团皮厚，让它站在路上。滴答站在路边，等浊走过来。
> 不急，摆好了再开始。
