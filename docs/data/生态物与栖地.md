# 生态物与栖地（设计表）

> **第二阶段备用（2026-10-22）**：单星肉鸽的首发版本不做生态布置和栖地（原因见 [03](../03_星球与演化.md) 第 9 节）。本表保留，供以后做「生态物作为奖励」或扩展更多星球时使用。

> 规则见 [03 星球与演化](../03_星球与演化.md) 第 7 节。产出是「每天」的量，小数表示平均（例如 0.5 = 两天一份）。花费里的「露水」来自战斗结余和露井。

## 2. 栖地配方（20 个）

- 配方里的生态物要在**相连的 7 格以内**（一格加一圈）。多放别的生态物没关系。
- 一个生态物只能属于一个栖地。重叠时取生机更高的那个。
- 「吸引」后面的数字是权重；带条件的只在条件满足时参加抽签。
- 栖地手帐里，没发现的配方只显示一句提示，例如湖岸：「湖水边，软软的绿色……」。

### 2.1 检查
- 36 个系列里，除了开局送的苔团、灯芯以外，每个系列都至少有一个栖地可以吸引（苔团和灯芯也有，方便配育）。
- 每颗星至少有 3 个可建的栖地；苔眠星有 5 个（湖岸、菜畦、林间、夜灯、草坡），用来教学。
