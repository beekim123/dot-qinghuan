# 13 开发计划与范围

版本 v3.1。替换“先直接做 Godot 小战场”的旧建议。当前要验证的是完整循环与两种画风，不是孤立棋盘。

## 1. 当前交接

本包只修订文字需求并提供提示词。没有创建新画面、HTML 或 Godot 工程，也没有把过去画面当作通过验收的资产。执行入口为 16，规则为 03/04/09/11/data/战场模板。

## 2. 下一位 AI 的原型工作

一次完成两个自包含离线 HTML：原生 WebGL2；星球 360° 选地、转场、自由布阵守心、三波自动战斗、真实胜败、结算回星及重试；像素和线条风各一份。两版同种子、同构图、同玩法，仅美术不同。按 16 自检，不必逐阶段等用户批准，不创建参考图片或导入外部资产。

## 3. 通过后才进入的阶段

用户选定画风 → 按 14 重新确认 Godot Demo → 完整单星肉鸽 → 内容扩充 → 打磨与发布。完整游戏仍保留局内成长、局外养成、小院、结缘、露水、心灯与传承，但不把这些未实现系统塞进原型用假按钮表现。

## 4. 不能削掉的原型部分

两版均须完整。不能删星球、只留棋盘；不能删真实寻路、只放固定路线；不能删失败、让程序自动赢；不能删回星写回、只播净化演出；不能用全三维小妖或整图摇摆代替二维原创动画。

时间/性能不足时先减少装饰、粒子、非必要后期和地貌变体，不改变这条核心闭环。不能提前写“已通过”来代替真实验证。

## 5. 已确认与默认

已确认：全向星球只选地、独立 HD-2D、方案 A 自由方格、中心守心、多向寻路、二维角色、两份完整 HTML、像素/彩色线条比较、原创纯代码美术、无图片参考。

默认可调整：11×7、约 40° 俯角、三个入口、480×270 像素内部画面、16 的光照/线粗初值。七只幼形来自原有图鉴，是本次小切片选择，不代表新创物种。最终画风、具体造型与线条质感仍由设计者看新原型后决定。

正式游戏的结缘操作、主角外观、长线时长、平台扩展等保持原文档规划，未在本次得到新增确认。不要把它们变成阻止当前工作的问题，也不要擅自扩展实现。
