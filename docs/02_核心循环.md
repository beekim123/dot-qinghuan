# 02 核心循环（单星肉鸽版 · v3）

> 2026-10-22 起的方向：**目前只做一颗星球；每一局进去都从头开始（肉鸽结构）；局内战斗，局外养成。**
> **v3（同日）：星球只当地图；选好落点后进入一个独立的 HD-2D 立体沙盘打仗。**
> 旧版的「6 颗星球长线战役」已归档到 [future/](future/)，以后扩展时再用。

## 1. 一句话

每一局，清星人带着几只小妖，来到一颗刚被浊染灰的苔眠星（地形每局重新生成）。在星球上一次次选落点，钻进那块地变成的小沙盘里布阵打浊，结缘新的小妖，让队伍在这一局里长大。要赶在浊泉越来越强之前，让星球一步步演化，最后封住三口浊泉、唤醒星心。不管成功还是失败，回到小院都能带回星砂、解锁新东西，再带一只小妖回家，下一局就更强。

## 2. 三层循环

```
┌─ 秒 ─── 一场战斗（局内） ──────────────────────────────────────────┐
│ （HD-2D 沙盘）看入口与动态通路 → 自由摆位 → 自动战斗 → 增援、放技能 → 净化沙盘     │
└───────────────────────────────────────────────────────────────────┘
          ↑ 带队伍进去                     ↓ 露水、经验、结缘、清亮格
┌─ 分钟 ── 一局（局内，约 40–50 分钟） ─────────────────────────────────┐
│ （星球地图）每个时辰从 3 个落点里选一个（战斗 / 露泉 / 行商 / 奇遇 / 泉主）│
│ → 队伍升级、化形、合流，拿星签 → 星相演化 → 封泉 → 唤醒星心（胜）       │
│                              或者 心灯耗尽（败）                     │
└───────────────────────────────────────────────────────────────────┘
          ↑ 选载具、选开局小妖、带传承小妖     ↓ 星砂、羁绊、传承、解锁
┌─ 长线 ── 小院（局外，永久） ─────────────────────────────────────────┐
│ 心灯之树升级 → 小妖羁绊等级 → 传承小妖 → 解锁载具 → 浊深挑战 → 故事碎片 │
└───────────────────────────────────────────────────────────────────┘
```

| 层 | 玩家想要的 | 驱动 |
|---|---|---|
| 一场战斗 | 赢得漂亮：心灯不掉、小妖不睡着、多存露水 | 心灯是整局共用的命，每掉一点都疼；结余的露水能在行商花 |
| 一局 | 组出一套顺手的队伍，看星球一步步变绿，打赢星心 | 每个时辰的落点选择、星相演化、越来越强的浊泉 |
| 长线 | 解锁新小妖、新载具，把喜欢的小妖练成「传承」，挑战更高的浊深 | 星砂、羁绊等级、传承栏、故事碎片 |

## 3. 什么在局内，什么在局外

| 东西 | 局内（每局清零） | 局外（永久保留） |
|---|---|---|
| 星球 | 地形、浊、清亮、星相、浊泉，每局都重新生成 | 只记录历史最好成绩和每日星球的结果 |
| 小妖 | 等级、形态、星级、本局得到的天赋 | 种类的**羁绊等级**；**传承小妖**（带回家的个体） |
| 资源 | 露水（局内货币）、心意、星签、心灯 | 星砂（局外货币） |
| 解锁 | — | 开局可选的小妖、载具、心灯之树、浊深、故事 |

**设计原则**：局外养成只让玩家「更有选择、更从容」，不让数值无限膨胀。小院全部升满，大约让一局轻松 30%，而不是碾压。挑战留给浊深。

## 4. 一局的流程

| 阶段 | 玩家做什么 | 时长 |
|---|---|---|
| **出发准备**（小院） | 选载具；从已解锁的小妖里选 3 只开局；带 1–3 只传承小妖；选浊深 | 1 分钟 |
| **降临** | 星球生成，镜头从星海拉到星球；灯婆婆说一句话 | 15 秒 |
| **选落点** | 星球上标出 3 个候选落点（能挑战泉主时多一个），每个显示类型、地形、浊气和奖励预览，选一个 | 不限 |
| **进入沙盘** | 星球拉近那块地 → 像素溶解 → 那块地变成一个 HD-2D 立体沙盘（地貌和星球上一致）→ 孔明灯落到心上 | 5 秒 |
| **落点内容** | 战斗在沙盘里打；休息、购物、事件是一个面板（背景是那块地的沙盘），见第 5 节 | 0.5–4 分钟 |
| **回星** | 沙盘净化 → 溶解回星球 → 那块地一圈圈亮起来；时辰前进；一天的最后一个时辰结算「浊潮」（浊泉变强、回浊） | 5 秒 |
| **星相演化** | 清亮度到阈值时：全星演出、心灯 +3、出阵上限 +1、新的浊泉可以挑战 | 6 秒 |
| ……重复选落点…… | | |
| **星心战** | 要到繁茂，并且另外两口浊泉都封住后才能打 | 5 分钟 |
| **结局** | 胜：清欢演出；败：「灯熄了」 | 30 秒 |
| **带回家** | 选 1 只（胜利时 2 只）小妖作为传承；结算星砂和羁绊 | 1 分钟 |

## 5. 落点的种类

每个时辰，星球上出现 3 个候选落点（在不同区域，彼此至少相隔 4 格），类型按权重抽，**至少有一个守心**。能挑战泉主时，泉主作为第 4 个选项额外出现。

| 落点 | 图标 | 内容 | 权重 |
|---|---|---|---|
| **守心** | 灯火 | 守心战（3 波）。星球上净化 3 圈。收获三选一 | 50 |
| **浊化群** | 紫眼 | 结缘战（自走棋式），打 2–4 只浊化小妖。净化 1 圈。洗净的全部可以结缘；额外露水 +15 | 20 |
| **露泉** | 水滴 | 不战斗。三选一：心灯 +4 / 全队 +1 级 / 任选一只立刻化形 | 10（第一天夜里起） |
| **行商** | 蜗牛 | 不战斗。用露罐里的露水买心意、蛋、星签、心灯回复 | 10 |
| **奇遇** | 问号 | 一段小事件，2–3 个选项（例如「一只迷路的芽芽想跟你走」「一口古井：投 10 露水许愿」） | 10 |
| **泉主 / 星心** | 漩涡 | 首领战，见 [04](04_战斗.md) | 条件满足时额外出现 |

## 6. 失败与压力

- **心灯**是整局共用的命（基础 12）。任何一场战斗里浊碰到心，扣的都是心灯；心灯归零，这一局就结束。
- **浊潮**：每过一天（4 个时辰），所有活着的浊泉等级 +1（敌人更强），每口浊泉还会让附近 2 格清亮的地重新变浊。所以不能无限慢慢刷。
- **除此之外没有惩罚**：失败也能带回星砂、羁绊和一只传承小妖。

## 7. 一局的节奏示例（第 5 局，浊深 0）

| 时辰 | 落点 | 发生了什么 |
|---|---|---|
| 第 1 天 · 晨 | 守心 | 开局三只（滴答、苔团、灯芯）加上传承的瓢瓢。赢了，清亮度 13%，星相到「初醒」，出阵 +1 |
| 午 | 浊化群 | 两只浊化茶烟。洗净后结缘一只，另一只合流（茶烟升到 2 星） |
| 暮 | 守心 | 拿到星签「潮声」（水属性 +10%） |
| 夜 | 行商 | 用 40 露水买了一个蛋（孵出萤子）和两份心意 |
| （浊潮：浊泉 2 级，回浊 4 格） | | |
| 第 2 天 · 晨 | 泉主 | 打浊化的菌山。封住第一口浊泉，心灯 +5 |
| 午 | 守心 | 清亮度 28%，萌青。滴答 6 级，化形成涟涟 |
| 暮 | 奇遇 | 「芽芽想跟你走」→ 送一份苔饼，结缘 |
| 夜 | 守心 | 夜战，萤子和灯芯的光很重要。掉了 3 点心灯 |
| （浊潮：浊泉 3 级） | | |
| 第 3 天 · 晨 | 露泉 | 选了「心灯 +4」 |
| 午 | 泉主 | 打浊化的月漪。封住第二口 |
| 暮 | 守心 | 清亮度 46%，繁茂。星心之泉解封 |
| 夜 | 星心 | 打眠眠。胜利，清欢 |
| 结算 | | 星砂 +178；涟涟带回家当传承；滴答、茶烟的羁绊升级 |

一共 12 个时辰，约 45 分钟。

## 8. 节奏规则

1. **每个时辰都要有选择**：三个落点不能都是同一种奖励。
2. **每局都要有「这局不一样」的东西**：地形、浊泉位置、出现的浊化小妖、星签、奇遇，至少三样每局不同。
3. **前 10 分钟就要让玩家看到星球明显变化**：第一次星相演化在第 1–2 场战斗后。
4. **失败要快**：从心灯归零到能开下一局，不超过 1 分钟。
5. **头 5 局的局外解锁要密**（几乎每局都有新东西），之后再放缓。
