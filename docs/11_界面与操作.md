# 11 界面与操作（v3）

> v3.1：两种画风的界面信息结构相同，画法分别按 09。以下含完整游戏 UI 规划；当前只实现 16 的星球、布阵、战斗、结算，不照搬旧 demo，不制作未实现页面的假按钮。

## 1. 原则

1. **场景是主角**：星球视图里星球占画面中间偏左的大部分；战场里沙盘占画面中间，界面只占四边的窄条。
2. **布局围绕场景**：顶栏、右侧面板、底部出阵栏。
3. **一个时刻只问一件事**：右侧面板只显示当前阶段需要的信息和按钮。
4. **少弹窗**：信息优先用场景里的小标签（例如「各方向来浊预告」「+1 露水」）和右侧面板，弹窗只用于结缘、收获和结算。
5. **能暂停就不催**：所有需要操作的地方都可以暂停或不限时。
6. **画风统一**：像素版用色块与像素边缘，线条版用轮廓与色面；系统字体，无外部字体。两版信息、控件位置一致（见 09）。

## 2. 主要界面

### 2.1 星球视图（选落点）


- 顶栏：天数和时辰、星相和下一档进度、三口浊泉的状态（已封 / 等级 / 星心之泉）、心灯、露罐、设置。
- 星球上：候选落点是会呼吸的小标记（图标 + 编号），鼠标停上去时把那块落点区域的 19 格描边；浊泉是紫色漩涡，带等级数字。
- 右侧面板：每个落点一张小卡片，选中后显示详情（第 2.2 节）。
- 底栏：队伍按钮、本局的星签（悬停看说明）、心意数量。

### 2.2 落点详情
- 类型、地形、最近浊泉的距离和方向、浊泉等级、浊气、预计来浊；
- **地貌家族和文字提示**（例如「林间，中心守心，三个方向来敌」）；
- **落点特征**（例如「夜战」「露眼 ×2」）；
- **能看到的浊化小妖**（剪影，见过的显示头像）；
- **预计新清亮格数**、**露眼格数**；
- **奖励预览**（守心：三选一的三个类别；浊化群：可结缘的小妖；泉主：稀有星签）；
- 「就去这里」按钮。

### 2.3 布阵（战场）


- 左栏（约 120 宽）：属性羁绊和当前生效的相邻效果；右栏（约 160 宽）：当前阶段的信息和按钮；底栏：出阵栏和备战席。
- 拖小妖到沙盘上：能放的格子顶面描边发亮，不能放的红边并说明原因；射程范围的格子整片变亮；会生效的相邻效果用一条发光的细线连起来（上下左右）。
- 鼠标停在格子上：左下角显示这一格的地形效果（例如「高台：射程 +0.5」）。
- 「自动布阵」会给出一个合理的摆法。

### 2.4 战斗（战场）
- 和布阵同一个布局，左栏换成**实时羁绊和露水收支**，右栏换成**波次进度**、速度、暂停、载具技能按钮（显示露水和冷却）。
- 沙盘上：心的上方显示心灯点；小妖头上有很细的体力条和灵力条，灵力满时闪一下；露水数字从产露的小妖和被打散的浊身上飘起来。
- 暂停时画面略暗，顶部显示「暂停中：可以换位、增援、放技能」。
- 胜利后：净化从心扩散到整个沙盘，然后结缘弹窗、收获三选一，最后转场回星球。

### 2.5 结缘


- 有几只就依次弹几次；也可以「全部先不了」。
- 成功率在送之前就算好显示，不藏数字。

### 2.6 收获三选一
三张卡片并排。卡片上：类别图标、名字、一句说明。星签卡片额外标「只在苔眠星有效」。

### 2.7 队伍（局内，按 Y）
- 一格一格的小妖头像（最多 8 只），角上标等级、星级，可化形时头顶有闪烁的小星。
- 选中一只：当前风格的二维形象（放大 4 倍，播放待机动画）、数值、资质星、天赋、技能（普攻、主技、相邻效果、特性、光源）。
- 按钮：化形、喂心意（+60 经验）、设为出阵 / 备战 / 后方、放走。
- 拖动调整出阵和备战顺序。

### 2.8 收获、行商、露泉、奇遇
- **收获三选一**：三张卡片并排，星签卡标「本局有效」。
- **行商**：慢慢的小铺子，商品一排卡片，价格用露水；买不起的变灰。
- **露泉**：三张卡片（心灯 +4 / 全队 +1 级 / 立刻化形一只）。
- **奇遇**：一段场景文字 + 一段话 + 2–3 个选项按钮，选项写清代价和结果。

### 2.9 一局结束
1. 胜利演出或「灯熄了」演出；
2. 统计卡：天数、战斗场数、清亮度、封泉、结缘；
3. 星砂结算（逐项滚动加上去）；
4. 羁绊结算（每个种类的羁绊条涨一点，升级时闪一下）；
5. **选传承**：从队伍里选 1 只（胜利 2 只）带回小院；传承栏满了就选一只放走；
6. 「回小院」按钮。

### 2.10 小院
- 画面是小院浮屿的近景，传承小妖在里面闲逛，可以拖动。
- 点心灯：灯婆婆说话、读故事碎片。
- 点心灯之树：升级树（一棵发光的树，每项升级是一颗果子，买了就亮起来）。
- 点窝：传承栏（摸一摸、看详情、放走）。
- 点石桌：图鉴（每个种类一页，显示羁绊等级和下一级解锁什么）。
- 点望远镜：**出发准备**（选载具、开局三只、传承小妖、浊深、每日星球），见 [06](06_小院与经济.md) 第 3 节。

### 2.11 设置
难度（陪伴模式）、画面开关（景深、泛光、动态光、粒子、天气、云影）、音量（五条总线）、界面大小、色弱模式、减少闪烁、震屏开关、进阶操作（目标偏好）、按键设置、语言。

### 3.2 布阵和战斗
见 [04](04_战斗.md) 第 14 节。

### 3.3 手柄的选格方式
- 战场里，左摇杆移动一个高亮光标，在方格之间上下左右移动。星球视图里，光标在候选落点之间跳。
- 拿着小妖时，光标所在格子显示能否放置和原因。
- 所有操作都能只用手柄完成（Steam Deck 目标）。

## 4. 新手引导

只教一次，用灯婆婆的话和高亮，不用整屏的教学弹窗。**第一局**用固定的教学种子，引导跟着这一局走：

| 步骤 | 教什么 | 怎么让玩家做到 |
|---|---|---|
| 1 | 转星球、选落点 | 第一个时辰只有一个落点（守心），其他地方暗着 |
| 1.5 | 星球和战场的关系 | 第一次转场进战场时，灯婆婆说：「这就是刚才那块地，放大了看。」回到星球时那块地亮起来 |
| 2 | 摆拦 | 给苔团，提示合法空格与邻格拦截范围，不锁定一条路 |
| 3 | 摆射 | 给滴答，显示射程与多入口威胁，不限制路边 |
| 4 | 开战、暂停 | 第一波中途自动暂停一次，灯婆婆说「累了可以停一停」 |
| 5 | 心灯 | 第一只浊碰到心时暂停，灯婆婆解释心灯是整局共用的 |
| 6 | 结缘 | 第一局第一场必有一只浊化瓢瓢，结缘必定成功 |
| 7 | 「产」和露眼格 | 第二场 |
| 8 | 三个落点的选择 | 第二个时辰起出现三个落点 |
| 9 | 星相演化 | 第一次升档时多一句解释 |
| 10 | 泉主 | 第一次出现泉主落点时 |
| 11 | 小院、传承、心灯之树 | 第一局结束回到小院时 |

- 每一步都可以在设置里「跳过所有引导」。
- 之后的新系统只在第一次出现时给一句话加一个「?」按钮，点开是一页简短说明。

## 5. 提示与反馈

- **场景标签**：星球视图里：浊泉等级、落点类型；战场里：各方向来浊预告、+1 露水、心灯 −1、苔团睡着了、可结缘。
- **悬停卡片**：任何小妖、浊、格子、星签、图标，鼠标停 0.3 秒（手柄选中）弹出小卡片。
- **数字**：所有加成在卡片里写清来源（例如「力 +25%：林地 +0、苔羁绊 +0、星签潮声 +10%、晴天 +15%」）。
- **震屏**：只有小浮岛落地、星心出场两处，可以关掉。

## 6. 无障碍

| 项目 | 做法 |
|---|---|
| 色弱 | 属性除了颜色还有形状图标（见 [04](04_战斗.md) 第 5 节）；可放 / 不可放除了颜色还有描边样式（实线 / 虚线）；色弱模式下预测路径与入口同时用线型和文字区分 |
| 文字大小 | 「标准」和「大」两档：「大」把界面基准从 960×540 改成 640×360，1080p 下界面放大 3 倍而不是 2 倍；像素字体始终整数倍放大，不会糊 |
| 反应速度 | 战斗随时暂停；默认波间自动暂停；轻松难度每波前也暂停 |
| 闪烁 | 「减少闪烁」关掉受击变白和闪电闪光，改用描边 |
| 动态 | 「减少动态」关掉震屏、像素溶解转场（改为淡入淡出）、星球自转 |
| 按键 | 全部可以重新绑定 |
| 难度 | 轻松 / 标准 / 挑战，随时切换 |

## 7. 完整游戏存档（当前原型按 16 的会话和重试规则）

- **局外存档**：小院的一切（星砂、心灯之树、羁绊、传承栏、解锁、故事进度、统计）。每次回到小院时保存。
- **局内存档**：当前这一局（种子、星球的浊和清亮、浊泉、时辰、队伍、星签、心意、露罐、心灯）。**每次回星（选落点之前）保存**；战斗中不存。
- 只有一个局内存档位：退出后再进游戏，从上一次回星的地方继续。不提供读档重来（肉鸽的惯例）。
- 每日星球单独记录，一天只能开始一次。

## 8. 当前原型结果页
胜败分别显示真实心灯、波次、露水及净化结果。胜利确认回星只结算一次；失败提供重试和回星，无虚假奖励。已经归零的心灯不能继续正常开战；重新开始与重试区别按 16。
