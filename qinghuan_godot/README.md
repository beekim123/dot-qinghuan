# 清欢小星

一个可反复游玩的、温柔的小型单星肉鸽。**Godot 4.7 / GDScript，已用 4.7.2 实际运行。**

## 运行

1. 用 Godot **4.7.2** 导入本目录的 `project.godot`。
2. 按 **F5** 运行项目，或点击右上角“运行项目”。
3. 不需要联网、插件或素材包。本目录即可独立运行；`docs/` 不参与运行。

也可命令行：

```sh
godot --path /你的路径/qinghuan_godot
```

建议窗口 1440×900。世界在 480×270（较小窗口 384×216）内部画面中渲染，按整数倍最近邻显示；清晰系统文字单独绘制。图像全部由调色板和代码运行时生成，没有外置图片、模型、字体或声音文件。

## 怎样玩

- **小院**：选择已解锁的伙伴，花永久星砂升级心灯之树，然后出发。最初是滴答、苔团、灯芯。
- **星球**：拖动真实的 362 格六边球，查看背面与两极。只能直接点击正面标记；右侧列表会先转向落点，再确认进入。
- **守心**：点下方小妖，再点任意合法空格。没有预铺道路；阵型改变实时寻路。右键收回。推荐布阵适合第一次体验，但不是唯一可行阵型。
- **战斗中**：空格开始／暂停，Tab 在 1×／2×／3× 间切换，Q 使用灯照。数字 1–7 选伙伴。可以暂停后布阵、换位、增援、唤醒。
- **露水**：战中增援与换位花费露水；睡着的小妖选中后点原格，花 4 露水唤醒。灯照花 6 露水，有 18 秒冷却。剩余露水进入露罐，可在行商使用。
- **成长**：守心胜利全队升一级，奖励可选结缘／补给／修习。达到 3 级后，在星球上点击伙伴卡片即可免费化形。露泉也能直接化形。
- **心灯**：整局共用，不会在战斗后自动回满。心灯耗尽便结束本局；小妖只是睡着。
- **目标**：洗净土地提升星相，封住两口浊泉，达到繁茂后洗净星心 **眠眠**。每四个时辰未封的浊泉增强，并让附近少量土地回浊。
- **回家**：胜败都获得星砂，解锁本局结缘过的开局伙伴，并选一只传承。异种传承额外加入开局；与开局同名时，该伙伴从 2 级开始。

### 六种定位

| 伙伴 | 定位 | 作用 |
|---|---|---|
| 滴答 → 涟涟 | 水／射 | 水珠、减速、相邻苔伙伴恢复 |
| 苔团 → 苔墩 | 苔／拦 | 邻格拦截、承受侵蚀、保护相邻伙伴 |
| 灯芯 → 灯盏 | 暖／溅 | 范围火团、相邻增力 |
| 茶烟 → 茶雾 | 汽／控 | 茶香减速、短暂安睡 |
| 萤子 → 萤火 | 光／射 | 连锁光点 |
| 芽芽 → 叶叶 | 苔／援 | 回复最疲惫的伙伴 |
| 瓢瓢 → 大瓢 | 水／产 | 产露，露眼更快 |

## 这版的内容

- 一颗每局重新生成地形与浊泉的真实 3D 星球：362 区域、12 五边格。
- 六种地貌的独立厚度方格沙盘，三向入口、实时 BFS、可校验的自由布阵。
- 七个原创像素系列与化形，局部逐帧待机／出手／移动／受击／睡眠动作。
- 浊团、灰絮、大浊、泉主与老苔龟眠眠；三波自动守心、真实胜败。
- 守心、露泉、行商、封泉、星相、时辰压力、结缘、修习、化形。
- 三项各三级的小院升级、开局种类解锁、一只传承、本地永久存档。
- 最短主线六场战斗，约八分钟模拟时间；正常选择、布阵与休息后约 10–20 分钟，支持加速。

## 存档

永久进度自动写到 Godot 的 `user://qinghuan_meta.json`。局内进度不跨退出保存；退出应用后从小院重新出发。不同平台路径由 Godot 管理（编辑器“项目 → 打开用户数据文件夹”可查看）。删除该 JSON 会重置永久进度。

## 验证

详见 `TEST_REPORT.md`。测试不需要第三方库：

```sh
godot --headless --path . --script tests/test_battle.gd
godot --headless --path . --script tests/test_run.gd
godot --headless --path . --script tests/test_ui.gd
```

首次使用请先用编辑器导入项目，以生成脚本类缓存。自动测试会测试写入永久进度，**请使用隔离的 Godot 用户数据目录，不要对自己的游戏存档运行测试**。例如 Linux 使用临时 `XDG_DATA_HOME`、`XDG_CONFIG_HOME`、`XDG_CACHE_HOME`。

取舍、具体数值和没有实现的文档大范围内容，见 `DECISIONS.md`。
